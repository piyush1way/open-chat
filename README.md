# Open Chat

I want to build a modern random stranger chat website called StrangerConnect, inspired by the concept of Omegle.

I am a beginner developer. Please generate clean, maintainable code and explain the important decisions.

DESIGN:

- Modern, premium-looking interface.

- Dark theme with black/navy background.

- Attractive accent colors.

- Minimal and clean layout.

- Fully responsive on desktop and mobile.

- Smooth animations and transitions.

LANDING PAGE:

- StrangerConnect logo and navigation.

- Main heading: Meet someone new. Start a conversation.

- Subtitle explaining anonymous random conversations.

- Prominent Start Chatting button.

- Small section explaining how it works.

- Privacy and safety information.

- Footer with Terms, Privacy and Contact links.

CHAT PAGE:

- Chat window with message bubbles.

- Separate visual styles for my messages and stranger messages.

- Message timestamps.

- Text input and Send button.

- Next Stranger button.

- Disconnect button.

- Report and Block buttons.

- Connection status: Searching, Connected, Disconnected.

- Searching animation while finding a stranger.

- Empty state before a stranger is found.

IMPORTANT:

- For now, build the frontend only.

- Use realistic mock data for demonstrating the interface.

- Do not pretend random matchmaking or real-time messaging is working yet.

- Keep frontend components separate and organized.

- Do not add unnecessary authentication or payment features.

- Do not put API keys or secrets in frontend code.

At the end, explain the generated project structure and how I can test the frontend.
